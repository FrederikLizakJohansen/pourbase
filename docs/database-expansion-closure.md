# Database expansion round: closing release

This round has a fixed scope: the 44 catalogued releases and the recorded
candidate inventories. The closing audit checked 197 task records, carrying
85 completed reviews forward and preserving 111 held/deferred records. These
records include parent tasks and overlapping follow-ups; they are not 111
independent import batches. One already-reviewed package supplies the closing
release. Further source searches, body variants and model extensions belong
to a separately scoped round.

The closing release retains 27 NEA observations across 11 new species, providing
26 selectable properties and one reported entropy with a scientific exclusion.
All previous observations and preferred values remain. The bundled database
contains **1,771 species and 5,268 reported observations**, across 75 systems,
with 33 buffered references. See the
[cyanide/thiocyanate source review](sources/nea-iron-cyanide-thiocyanate.md).

The source and reuse reviews carry forward. NEA data use the supplied OECD
clarification, attribution and downstream acknowledgment conditions. The new
K+ buffered reference reuses an existing openly released NBS observation.
Other sources retain their separate terms and permission holds.

The [follow-up register](database-follow-ups.csv) preserves the remaining work
and the condition needed to resume each item. R06 original numerical-source
access and R07 independent magnesium activity calibration remain unresolved.
The six original experimental crystalline-G gaps also remain. Historical target
coverage is **116/131 properties: NEA 28/28 and NIST 88/103**. Computational
fallbacks remain distinct from experimental coverage.

The audit reconciled stale labels: MP17 cobalt was already released by MP17a;
the expanded HERACLES graph was screened under R14; the Mg2+ reference is now
available, while the Fe-pyroaurite admission still needs original-cell and
phase-specific validation. Remaining source and policy questions are retained.
No unresolved scientific or permission condition is silently marked satisfied.

Closure means this finite delivery, its release checks and documentation are
complete. It does not claim that every native value is reusable or that all
follow-up research has been resolved. The former 16/18 headline count records
review coverage; it is not a forecast of remaining effort.
