# The app

The app has four tabs along the top.

| Tab | What it shows |
|---|---|
| [Periodic table](periodic-table.md) | The stable species of every element at one pH, potential and temperature |
| [An element](system.md) | One element's diagrams and the values behind them; the tab carries the element's name |
| [Database](database.md) | Every species, value and source |
| [Selection policy](policy.md) | The rule that picks the recommended values, as editable text |

Ctrl+K searches elements, species, sources and commands. Every change is undoable with Ctrl+Z. Sessions are
saved as `.pourbase.json` (File → Save session), and File → Copy Python code gives the equivalent script.

The theme follows the system, or View → Theme sets it.
